# Project 2 implementation plan

Goal: A reproducible air quality EDA project and Word report for BIOSTAT 721.
Architecture: A single-year cleaning function feeds daily data, annual tables, and monthly summaries. RMarkdown renders the report with hidden code.
Tech stack: R, dplyr, tidyr, ggplot2, knitr, rmarkdown, Pandoc.
Authorization: User requested the complete package including GitHub commits and ZIP.

Design: Keep existing ICA16 files and add Project2/. Remove exact raw duplicate rows before replacing negative concentrations with zero and calculating daily means. Keep missing observations missing; do not invent absent dates. Default ozone units are ppm; ppb is optional. Plot CO and ozone in separate colored panels with independent labeled y scales. Plot monthly PM2.5 means as lines and points by year, with no continuation beyond April 2020.
Alternatives: A shared y scale hides ozone variation; a dual axis complicates interpretation. Facets preserve the original ppm units and show both seasonal patterns.

Review focus: Duplicate weighting; correction before averaging; all-missing days; ozone conversion; unequal monthly sample sizes.
